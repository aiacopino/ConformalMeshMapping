\section{Outlook}
The algorithm could be extended to cover non-convex regions by implementing a homotopy method, which relaxes the target region and computes a sequence of intermediate mappings, where each solution is the initial guess for the subsequent mapping. This is a common approach to ensure convergence of iterative solvers when the initial guess is not sufficiently close to the target solution. We omit this extension due to time constraints, but it is a promising direction for future work.
