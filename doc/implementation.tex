\section{Documentation and Implementation} \label{chap:implementation}

The language of choice is Python because there is extensive support for numerical methods and scientific computing. The code is structured in a modular way and can be found on Github: 

\url{https://github.com/aiacopino/ConformalMeshMapping}.

To run experiments, simply run the file \texttt{main.py}, which will execute the code in \texttt{convergence\_tests.py}.
The main implementation of Wegmann's method is in \texttt{wegmann.py}, which contains the class \texttt{WegmannSolver} with methods for each step of the algorithm. The code is hopefully well-documented with docstrings and comments for clarity.

\subsection{Discretisation} \label{chap:WegmannImplementation}
We have followed the exact implementation steps described in \cite[§5]{Wegmann1978_newtonverfahren}, which details two different methods in terms of discretisation (Verfahren 1 and 2). We have implemented both in order to compare the results to Wegmann's claims, see the overview in Section \ref{chap:experiments}. 
Note that in order to avoid confusion with the word 'method' in programming, we have chosen to use the German word 'Verfahren' to refer to the two different approaches described in Wegmann's paper.

The algorithm fundamentally solves for the boundary correspondence function $S_k$, which maps the angle $\theta\in[0,2\pi]$ of the unit disk to the parameter $s\in[0,2\pi]$ of the target curve. Since $S_k$ winds around the unit circle once, it must satisfy $S_k(2\pi) = S_k(0) + 2\pi$. To allow for spectral processing via Fourier transforms, this is resolved by decomposing the map into the identity term plus a $2\pi$-periodic displacement function $\sigma_k$ \cite[Eq. 3.2]{Wegmann1984_convergence_iterative_method}:
\begin{equation}
    S_k(\theta) = \theta + \sigma_k(\theta).
\end{equation}

\subsubsection{Numerical Solution to the Riemann-Hilbert Problem}

Since we assume $\psi$ to map from the unit disk $\disk$, the integral equations can be explicitly solved by discretization and trigonometric interpolation \cite[§5]{Wegmann1978_newtonverfahren}:
At each iteration $k$, take $N=2n$ equidistant points $\zeta_k=e^{i\theta_k}$ on the boundary of the disk, where $\theta_k = \theta_0 + \frac{\pi k}{N}$.

To solve the linear Riemann-Hilbert problem equation \ref{eq:RHproblem} for $\psi_{k+1}$ at each iteration $k$, the method relies heavily on the evaluation of Cauchy-type integrals over the unit circle:
\begin{equation}
    F(z)= \frac{1}{2\pi i} \displaystyle \int_{\del\disk} \frac{\varphi(\zeta)}{\zeta - z} d\zeta
\end{equation}
for some density function $\varphi:\del\disk\to\C$.

This integral is defined everywhere except directly on the boundary $\partial\mathbb{D}$. 
There, the uniform limits $F^+$ from the left and $F^-$ from the right of the boundary are defined by the Plemelj formulae \cite[Eq. 17.2]{Muskhelishvili1977}
\begin{equation}
    \begin{matrix}
        F^+(z) = \frac{1}{2} \varphi(z) + \frac{1}{2\pi i} \int_{\del\disk} \frac{\varphi(\zeta)}{\zeta - z} d\zeta, \\
        F^-(z) = -\frac{1}{2} \varphi(z) +\frac{1}{2\pi i} \int_{\del\disk} \frac{\varphi(\zeta)}{\zeta - z} d\zeta.
    \end{matrix}
\end{equation}
These are equivalent to \cite[Lemma 14.2e]{Henrici1986_vol3}
\begin{equation}
    \begin{matrix} \label{eq:F+Hilbert}
        F^+(z) = \frac{1}{2}\varphi(z) + \frac{i}{2} K \varphi(z) + \hat\varphi, \\
        F^-(z) = - \frac{1}{2}\varphi(z) + \frac{i}{2} K \varphi(z) + \hat\varphi,
    \end{matrix}
\end{equation} where $\hat\varphi$ is the mean value of $\varphi$.

The Plemelj-Sokhotski formulas \cite[§ 17]{Muskhelishvili1977} define the limiting boundary values from the interior ($F^+$) and the exterior ($F^-$) of the disk. 
These relate via the jump condition \cite[Eq. 17.3]{Muskhelishvili1977}:
\begin{equation}\label{eq:Plemelj_Diff}
    F^+(\zeta_k) - F^-(\zeta_k) = \varphi(\zeta_k).
\end{equation}
Furthermore, the sum of the limits corresponds to the Cauchy Principal Value integral, which on the unit circle satisfies \cite[Lemma 14.2e]{Henrici1986_vol3}, \cite[Eq. 17.4]{Muskhelishvili1977}:
\begin{equation}\label{eq:Plemelj_Sum}
    F^+(\zeta_k) + F^-(\zeta_k) = i\mathcal{H}(\varphi)(\zeta_k)+\hat\varphi.
\end{equation}
Adding Equations \ref{eq:Plemelj_Diff} and \ref{eq:Plemelj_Sum} yields the Plemelj projection for the interior analytic boundary value:
\begin{equation}\label{eq:Plemelj_Projection}
    F^+(\zeta_k) = \frac{1}{2} (\varphi + i \mathcal{H}(\varphi) + \hat\varphi).
\end{equation}

    Note also $\zeta\in\del\disk$.
\end{remark}

\bigskip\noindent\textbf{The Homogeneous Solution}\\
Let $X$ be a fundamental solution to the homogeneous RH-problem \cite[§ 40]{Muskhelishvili1977}
\begin{equation}
    F^+(\zeta) = G(\zeta) F^-(\zeta)
\end{equation}\red{WHAT IS G}
Following \cite[§ 89, page 99ff]{Muskhelishvili1977}, we first find the homogeneous solution $X(z)$ to
\begin{equation} 
    \text{Re}(\frac{\psi_{k+1}}{i\dot\eta(S_k(\zeta))})= 0
\end{equation} based on the tangent angle of the target boundary. 
For $g_k$ the tangent vector of the target boundary and a suitable choice of branch of the argument \cite[page 457]{Wegmann1978_newtonverfahren}, Wegmann defines the Hölder-continuous
\begin{equation}
    \Theta(\zeta) := \arg(\zeta^{-2} \frac{g_k} {\overline{g_k}} ).
\end{equation} 
In the code, this choice of argument function is dealt with via \texttt{np.unwrap()}.
Write $g_k = |g_k|e^{i\arg(g_k)}$ and $\overline{g_k}=|g_k|e^{-i\arg(g_k)}$ to get
\begin{equation}
    \arg(g_k/\overline{g_k})=\arg(e^{2i\arg(g_k)})=2\arg(g_k).
\end{equation}
Since $\zeta\in\del\disk$, we have $\arg(\zeta^{-2})=-2\theta$.
Hence,
\begin{equation}
    \arg(\zeta^{-2} g_k/\overline{g_k})=\arg(\zeta^{-2})+\arg(g_k/\overline{g_k}) 
    \implies \Theta(\zeta) = 2\arg(g_k) - 2\theta.
\end{equation}
\red{Note that $\Theta$ is a measure of how much the polar angle of the coordinate $\del\disk\ni\zeta=e^{i\theta}$ is rotated by the conformal map onto the tangent angle on $\Gamma$.}

Now, define \cite[Eq. 3.5]{Wegmann1978_newtonverfahren}
\begin{equation} \label{eq:Yintegral}
    Y(z) = \frac{1}{2\pi} \displaystyle\int_{\del\disk} \frac{\Theta(\zeta)}{\zeta - z} d\zeta = \frac{1}{2\pi i} \displaystyle\int_{\del\disk} \frac{i \Theta(\zeta)}{\zeta - z} d\zeta
\end{equation} 
to be the Cauchy integral of $\Theta$. By the Plemelj-Sokhotski formulas \eqref{eq:Plemelj_Diff}, the jump condition for $Y$ is given by:
\begin{equation}\label{eq:Yjumpcondition}
    Y^+(\zeta) - Y^-(\zeta) = \Theta(\zeta).
\end{equation}
By \cite[Eq. 3.6]{Wegmann1978_newtonverfahren}and \cite[page 105]{Muskhelishvili1977},
\begin{equation} \label{eq:X_homogensol}
    \begin{matrix}
%    \begin{rcases} 
        X^+ = \exp(Y^+ - \hat Y) \\
        X^-(z) = z^{-2} \exp(Y^-(z) - \hat Y)
%    \end{rcases} \implies X^- = z^{-2} \exp(Y^- - C).
    \end{matrix}
\end{equation}
where $\hat Y=\frac{1}{2}Y(0)$.
Moreover, combining \ref{eq:Plemelj_Projection}, \eqref{eq:Yintegral} and \eqref{eq:X_homogensol} yields:
\begin{equation}
    \log(X^+(\zeta)) = Y^+-\frac{1}{2}Y(0) = \frac{1}{2} \left(i\Theta + i \mathcal{H}(i\Theta)\right) = \frac{1}{2} \left(i\Theta - \mathcal{H}(\Theta)\right).
\end{equation}
Exponentiating yields the homogeneous solution on the interior of the disk. It remains to find the limiting function $X^-$ on the exterior of the disk.
Consider the ratio $$\frac{X^+}{X^-} = \frac{\exp(Y^+ - \hat Y)}{z^{-2} \exp(Y^- - \hat Y)} = z^2 \exp(Y^+ - Y^-)$$
Substituting the jump condition \ref{eq:Yjumpcondition} yields 
\begin{equation}
    \frac{X^+}{X^-} = z^2 \exp(\Theta) \iff X^- = X^+ \cdot z^{-2} \cdot e^{-\Theta}.
\end{equation}

\bigskip\noindent\textbf{The Inhomogeneous Solution}\\
With $X^+$ established, consider the density function $\rho$ (the \textit{Belegungsfunktion} \cite[§5]{Wegmann1984_convergence_iterative_method}):
\begin{equation}
    \rho =
    \begin{cases}
        \frac{g_k \cdot \text{Im}(f_k /g_k)}{X^+} & \text{ for Verfahren 1} \\
        \frac{g_k \cdot \text{Im}((f_k - \psi_k)/g_k)}{X^+} & \text{ for Verfahren 2},
    \end{cases}
\end{equation}
where $\psi_k$ is the previous step's analytic approximation. Note that this definition implies that the first iteration is always carried out using Verfahren 1.
To find the boundary values $\Phi^+$ and $\Phi^-$ of the particular solution, a second Cauchy integral using $\rho$ as the density is evaluated \cite[Eq. 3.7]{Wegmann1978_newtonverfahren}, \cite[Eq. 40.24]{Muskhelishvili1977}.
\begin{equation}
    \Phi(z) = \frac{X(z)}{\pi} \displaystyle\int_{\del\disk} \frac{\rho(\zeta)}{(\zeta-z)} d\zeta = \frac{X(z)}{\pi}F(z).
\end{equation}
While $F(z)$ could be evaluated using the spatial Hilbert transform, we apply a frequency-domain optimisation.
By analyticity of $F$, the numerical evaluation of the Cauchy integral can be done exploiting Fourier theory. The Plemelj projection $F^-$ on the outside of the disk corresponds to the Laurent series of $\rho$ (negative frequencies), while $F^+$ on the inside corresponds to the Taylor series \cite[Eq. 14.2-31, 14.2-32]{Henrici1986_vol3}.
Following \cite[Eq. 3.7 and p.464]{Wegmann1978_newtonverfahren}, the analytic functions $\Phi^+$ and $\Phi^-$ are then constructed by scaling the Cauchy integrals with the fundamental homogeneous solutions:
\begin{equation}
    \begin{matrix}
         \Phi^+ = 2i \frac{X^+(z)}{\pi}\int \frac{\rho(\zeta)}{\zeta - z} d\zeta = X^+ F^+ \\
         \Phi^- = 2i \frac{X^-(z)}{\pi}\int \frac{\rho(\zeta)}{\zeta - z} d\zeta = X^- F^-.
    \end{matrix}
\end{equation}
Finally, these components are combined to yield the initial analytic update function $\psi_0$ \cite[Eq. 3.8]{Wegmann1978_newtonverfahren}:
\begin{equation}
    \psi_0 = \frac{1}{2} \left( \Phi^+ + \overline{\Phi^-} \right).
\end{equation}
This procedure reduces the evaluation of the singular boundary integral to $\mathcal{O}(N\log N)$ operations \cite[page 109]{Henrici1986_vol3}.

\bigskip\noindent\textbf{Anchoring and Calculation of Correction}\\
$\psi_0$ is a particular solution to the inhomogeneous problem. The general analytic solution is given by \cite[Eq. 3.9]{Wegmann1978_newtonverfahren}
\begin{equation}
    \psi_{k+1} = 
    \begin{cases}
        \psi_0 + P X^+ & \text{ for Verfahren 1} \\
        \psi_k + \psi_0 + P X^+ & \text{ for Verfahren 2}.
    \end{cases}
\end{equation}
$P$ is a polynomial of degree 2 which is found by enforcing the uniqueness constraints for $\psi_{k+1}$.

To ensure the uniqueness of the conformal map as dictated by the Riemann Mapping Theorem, we must fix three real degrees of freedom. 
We enforce the anchoring condition $\psi(0) = 0$, which requires $\psi_{k+1}(0) = 0$. 
By the Mean Value Property \cite[Eq. 14.2-2]{Henrici1986_vol3} of analytic functions, the value of an analytic function at the origin of the unit disk is exactly the mean of its boundary values. Thus, evaluating the condition at $z=0$ yields:
\begin{equation} \label{eq:initcond_1}
    0 = \psi_{k+1}(0) = \psi_0(0) + P X^+(0) \implies P = -\frac{\underline{\psi_0}}{\underline{X^+}},
\end{equation}
where the underline here denotes the arithmetic mean over the discretised boundary points.

Once the properly anchored analytic function $\psi_{k+1}$ is constructed, the real-valued boundary correction step $U_k$ is extracted. Following \cite[Eq. 2.4]{Wegmann1978_newtonverfahren}, the update is the projection of the discrepancy $(\psi_{k+1} - f_k)$ onto the tangent vector $g_k$:
\begin{equation}
    U_k = \text{Re}\left( \frac{\psi_{k+1} - f_k}{g_k} \right).
\end{equation}
Finally, to prevent rotational drift of the parametrization during the iterative process enforcing the $f'(0) > 0$ condition of the Riemann Mapping Theorem the mean of $U_k$ is zeroed before the step is applied:
\begin{equation}\label{eq:initcond_2}
    U_k \leftarrow U_k - \overline{U_k}.
\end{equation}

\subsection{Uniqueness of the solution}
The three degrees of freedom fixed to ensure uniqueness of the conformal map are tracked as follows in the implementation:
\begin{itemize}
    \item $\psi(0) = 0$ (eq. \ref{eq:initcond_1}): The real and imaginary parts of the origin's image are fixed to the center of the target region, locking down two degrees of freedom (translation). In the implementation, this is enforced by shifting the target region such that its center lies on the origin, computing the conformal map, and then shifting the result back (\texttt{self.shift}).
    \item $\psi'(0) > 0$ (eq. \ref{eq:initcond_2}): This condition prevents rotational drift of the parametrization during the iterative process. This is enforced by zeroing the mean of the correction step $U_k$ before applying it to update the boundary correspondence function.
\end{itemize}
Furthermore, bijectivity of the map is guaranteed by construction via monotonicity of the parametrisation $S_k$, tracked by the property \texttt{self.is\_injective}.

\subsection{Solving the Interior Mapping}
Once we have the unique mapping between the boundaries, it remains to find the mapping for the rest of the mesh points in the interior of the disk. This is done by leveraging Cauchy's Integral Formula \ref{eq:CauchyIntegralFormula} in theory, but numerically unstable in practice for points near the boundary, as the kernel presents a singularity. 
By analyticity of the mapping (also on the interior) the negative Fourier coefficients of the boundary mapping vanish and the positive Fourier coefficients are exactly the Taylor coefficients. Hence, we can evaluate the interior mapping at any point by evaluating the Taylor series with the Fourier coefficients as coefficients, which can be done efficiently using Horner's method \cite{Burrus2003horner} as implemented in the \texttt{calculate\_interior\_mesh()} method.


\subsection{The Initial Guess Problematic}
Note that this is a Newton method and thus only guaranteed to converge locally due to the linearisation of the boundary. Hence why a "good" (close enough) initial guess is vital for numerical stability \cite[Thm. 5]{Wegmann1978_newtonverfahren}. 
Note that Wegmann proves this, but in his own testing only used the identity as initial guess; we have tried to do better (see experiments section \ref{chap:experiments}).

Apart from the simple identity initial guess, we have tried implementing two more sophisticated initial guesses. 
It is however worth mentioning that neither of those significantly improved our results; they are probably still way too far from the true solution.
\subsubsection{Star-shaped Initial Guess}
For strongly deformed but still star-shaped target regions, a radial projection of the target boundary onto the unit circle can be used as an initial guess. This is implemented in the \texttt{init\_initial\_guess\_starshaped()} method, which computes the initial boundary correspondence function $S_0$ by projecting each point on the target boundary radially onto the unit circle and then interpolating to get a smooth function.
\subsubsection{Non-Convex Initial Guess}
For the kite region, neither the identity nor the star-shaped initial guesses seem to be close enough to the true solution for the solver to converge with a useful amount of discretisation points. Hence why we tried using a "squished" version of the identity as an initial guess, which is implemented in the \texttt{init\_initial\_guess\_non\_convex()} method. This method takes the identity map and applies a non-linear transformation to it, effectively "squishing" the unit disk into a shape that resembles the target region more closely. The transformation is defined by a function that maps the unit circle to itself while introducing non-convexity, which can help the solver converge for highly non-convex target regions.

\subsection{Verfahren 1 vs. Verfahren 2} \label{chap:verfahren1-2}
In order to compare our results to Wegmann's, we have implemented both Verfahren 1 and Verfahren 2 as described in \cite[§5]{Wegmann1978_newtonverfahren}.
This leads to different convergence properties, as mentioned in \cite[§5]{Wegmann1978_newtonverfahren}, see experiments section \ref{chap:experiments}.

\subsubsection{Convergence and Plotting}
Note that we chose to output a plot in any event, not just when the solver converges, because plotting intermediate or divergent steps is a diagnostic tool used to generate the failure figures in Chapter \ref{chap:experiments}. This allows us to visually inspect the behaviour of the solver in cases where it fails to converge, which can be helpful for understanding the reasons for failure and for debugging purposes.
The actual status of the solver is tracked via \texttt{solver.status}, which can take the following values:
We define the solver as having \texttt{CONVERGED} if the condition that the approximation error $\lVert U_k \rVert$ is smaller than the user-defined tolerance parameter is met. We define \texttt{DIVERGED} as the condition that the approximation error exceeds a certain threshold (currently set to $10^5$) and \texttt{MAX\_ITER\_REACHED} if the solver does not converge within a maximum number of iterations (e.g. $10'000$).
Note that the above definition of convergence can lead to a situation where the solver is considered as having converged, but the resulting map is not actually conformal because the boundary parametrisation function $S_k$ is not injective, i.e. $\psi$ folds onto itself. This is checked via a boolean state variable \texttt{is\_injective = not np.any(S\_dot\_k <= 0)} and yields status \texttt{CONVERGED\_BUT\_NOT\_CONFORMAL}. 
In this case, it is advisable to try again with a different (closer) initial guess or with a smaller relaxation parameter or lower number of discretisation points.

\subsubsection{Accuracy} \label{chap:accuracy}
We define accuracy as the $L^2$-norm of the difference between the computed map and Gaier's known analytical solution, evaluated at the discretisation points on the boundary. Note that this is different from the convergence criterion, which is based on the approximation error of the solver's update steps and is not directly related to the accuracy of the final solution.

\subsubsection{Testing Other Target Regions}
For testing other target regions than the few already implemented, the user can simply define a new method in \texttt{convergence\_tests.py} analogous to the existing methods. The only requirement for the target region is that it must be simply connected and sufficiently smooth \cite[Theorem 1]{Wegmann1984_convergence_iterative_method}.
